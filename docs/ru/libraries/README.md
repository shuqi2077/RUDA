Вычислительные библиотеки реализуют операции, среда выполнения выполняет их на устройствах, а тензорная платформа их компонует. Названия библиотек описывают обязанности, а не идентичные API или полную функциональность с аналогичными именами библиотек CUDA.

## Слои интерфейса

- Интерфейсы ядра/запуска принимают привязки устройств и конфигурацию выполнения для разработки ядра и библиотек.
- Тензорные интерфейсы обрабатывают выделение, макеты и вызовы, обычно используя `RudaTensor<R>`.
- Интерфейсы Framework отправляются в библиотеки через такие компоненты, как `ruda-tensor-device`.

Операции с одинаковыми именами на разных уровнях могут иметь разные аргументы, типы возвращаемых значений и обработку ошибок. Проверьте пакет, путь к модулю и функцию вместе; Сигнатуры точек входа ядра не являются подписями тензорных точек входа.

## Использование направляющих

В руководстве по каждой библиотеке описаны ее назначение, функции, интерфейсы, контракты данных и ограничения. Явно выбирайте функции, необходимые для общего пути, а не предполагайте, что значения по умолчанию подходят для каждого устройства.
