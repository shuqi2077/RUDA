計算ライブラリはオペレーションを実装し、ランタイムがデバイス上でオペレーションを実行し、テンソル フレームワークがオペレーションを構成します。ライブラリ名は責任を説明するものであり、同様の名前の CUDA ライブラリと同一の API や完全な機能の同等性を示すものではありません。

## インターフェイス層

- カーネル/起動インターフェイスは、カーネルおよびライブラリ開発のためのデバイス バインディングと実行構成を受け入れます。
- Tensor インターフェイスは、通常 `RudaTensor<R>` を使用して、割り当て、レイアウト、呼び出しを処理します。
- フレームワーク インターフェイスは、`ruda-tensor-device` などのコンポーネントを通じてライブラリにディスパッチします。

異なるレイヤーで同じ名前の操作では、引数、戻り値の型、およびエラー処理が異なる場合があります。パッケージ、モジュール パス、および機能を一緒に確認します。カーネル エントリ ポイント署名は、テンソル エントリ ポイント署名ではありません。

## ガイドの使用方法

各ライブラリ ガイドでは、その目的、機能、インターフェイス、データ コントラクト、および制約について説明します。デフォルトがすべてのデバイスに適合すると仮定するのではなく、汎用パスに必要な機能を明示的に選択します。
